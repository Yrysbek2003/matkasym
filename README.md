# Matkasym — магазин + панель сотрудников

## Структура
- `index.html` — каркас страницы
- `css/styles.css` — стили
- `js/data.js` — данные и начальные товары (демо)
- `js/shop.js` — страницы магазина и корзина
- `js/api.js` — связь с сервером
- `js/staff.js`, `js/staff2.js`, `js/staff3.js` — панель сотрудников (заказы, склад, импорт, аналитика, настройки)
- `js/rules.js` — общие правила склада и ролей (использует и сервер)
- `server.js` — сервер (Node 18+, без зависимостей), `package.json`

## Запуск на компьютере
1. Установите Node.js 18 или новее.
2. В папке сайта: `ADMIN_PASSWORD=ВашПароль node server.js` (Windows PowerShell: `$env:ADMIN_PASSWORD="ВашПароль"; node server.js`).
3. Магазин: http://localhost:3000 · Панель сотрудников: http://localhost:3000/#staff (логин `admin`).
Если пароль не задан, сервер создаст случайный и напечатает его в консоли при первом запуске.

## Без сервера (демо)
Откройте `index.html` двойным кликом. Всё хранится в браузере; вход в демо: admin / admin123, manager / manager123. Заказы видны только на этом устройстве.

## Render.com
- New → Web Service, Build Command пустой, Start Command: `node server.js`
- Environment: `ADMIN_PASSWORD` (обязательно), `DATA_DIR=/var/data`, `TRUST_PROXY=1` (иначе лимиты попыток считаются на всех посетителей сразу)
- Подключите Disk (Mount Path `/var/data`), иначе заказы и фото пропадут при перезапуске.

## Что делает сервер
- пересчитывает цены и проверяет остатки сам (цену из браузера не принимает);
- хранит пароли в виде хэшей (scrypt), вход ограничен по числу попыток;
- менеджер видит только свои и свободные заказы, может менять статусы, заметки и остатки; цены, настройки, сотрудников и фото меняет только админ;
- оптовые и дилерские цены клиентам не отдаются;
- панель каждые 20 секунд проверяет новые заказы и подаёт звуковой сигнал.

## Роли
Администратор — всё. Менеджер — заказы, клиенты, заявки. Контент-менеджер — товары, сеты, импорт, аудит (цены не меняет). Склад — приход, списание, инвентаризация, отгрузка заказов.

## Версия 4.0
- сервер использует `js/rules.js`: резерв товара в активных заказах, списание при «Выполнен», журнал движений;
- вход сотрудников хранится в базе (не слетает при перезапуске), добавлена 2FA (Google/Microsoft Authenticator);
- менеджер не может подменить цены и суммы в заказах, секреты (токен Telegram) видит только админ;
- уведомления о заказах и заявках в Telegram (Настройки → Telegram);
- настройки компании, оплаты, оптовые коды и юридические тексты сохраняются на сервере;
- «старая цена» задаётся вручную в карточке товара (зачёркнутая цена больше не выдумывается).
